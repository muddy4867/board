# Folio — 나의 웹사이트 컬렉션

웹사이트를 카드로 모으는 개인 포트폴리오 대시보드입니다.

## 기능

- 프로젝트 추가·수정·삭제, 검색·분류·정렬·즐겨찾기
- 링크 붙여넣기와 드래그 앤 드롭으로 주소 자동 입력
- 대표 이미지 업로드, JSON 백업 내보내기·가져오기
- 메인으로 이동, 잠금, 15분 미사용 시 자동 잠금
- 서버에서 비밀번호 검증, 서명된 HttpOnly 세션 쿠키

## 실행

Node.js 22 이상이 필요합니다. 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm test
npm run preview
```

미리보기: http://127.0.0.1:4191

로컬 미리보기는 테스트 전용 비밀번호 `qa-password-only`를 사용합니다. 운영 비밀번호와 다릅니다. 미리보기 서버를 운영에 사용하지 마세요.

## 운영

Cloudflare Workers 호환 ESM Worker입니다. `npm run build` 결과는 `dist/server/index.js`입니다. GitHub Pages만으로는 서버 비밀번호 검증을 실행할 수 없습니다.

운영 환경의 비밀값으로 다음 항목을 설정합니다. 실제 값은 저장소에 포함하지 않습니다.

- `PORTFOLIO_PASSWORD`: 접속 비밀번호
- `PORTFOLIO_SESSION_SECRET`: 무작위 32바이트 이상의 세션 서명 키

현재 Sites 배포의 본인 계정 접근 제한은 호스팅 플랫폼에서 적용합니다. 다른 호스트로 옮길 때는 계정 접근 제한을 별도로 구성해야 합니다. 로그인 시도 제한은 Worker 인스턴스 메모리 범위입니다.

## 저장 방식

기본 프로젝트 5개가 포함되어 있습니다. 사용자가 추가·수정한 프로젝트와 이미지는 현재 브라우저의 localStorage에 저장됩니다. 기기를 옮길 때는 백업을 이용하세요. 브라우저에서 추가한 데이터는 이 저장소에 자동으로 올라오지 않습니다.

## 파일

- `web/`: 대시보드 HTML·CSS·JavaScript
- `worker/index.js`: 로그인, 세션 검증, 보호된 파일 제공
- `scripts/build.mjs`: 화면 파일을 Worker에 포함해 빌드
- `scripts/check.mjs`: 인증·접근 차단·잠금 검사
- `.openai/hosting.json`: 기존 Sites 배포 연결 정보
